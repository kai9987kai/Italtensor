# Acknowledgement

Italtensor is built on the Python scientific and desktop ecosystem. The project depends on NumPy, scikit-learn, TensorFlow/Keras when available, PySimpleGUI for the desktop interface, and pytest for verification.

The experiment workflow is informed by established machine-learning practice: split planning, stratified and chronological validation, learning-curve diagnostics, active-learning and data-acquisition planning, probability calibration, decision-threshold tuning, label-shift and prior-shift analysis, model-card style reporting, active-learning review loops, and lightweight dataset diagnostics for small local tabular problems.

The current implementation also draws from published and documented ideas including Keras model serialization, scikit-learn threshold tuning and validation utilities, conformal prediction, calibration, cumulative gains and lift charts, decision-curve analysis, label-shift estimation, counterfactual recourse, monotonic constraints, tensor-network/MPS models, and practical model monitoring.

Thanks are due to the maintainers and authors behind the open-source libraries, papers, and documentation that make local experimentation possible, and to users who test the tool on real datasets and turn rough prototypes into usable workflows.

Italtensor does not claim endorsement from any referenced project, author, institution, or library maintainer.
